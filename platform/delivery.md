# Delivery

Load when changing CI, release, or deployment behavior.

- Separate build, test, release, and deploy responsibilities; promote immutable artifacts.
- Run project-appropriate formatting, static analysis, tests, and build checks.
- Choose rolling, blue-green, canary, or feature-flag rollout from rollback cost and exposure risk.
- Define health checks, traffic-shift criteria, rollback or forward-fix, and migration compatibility before high-risk releases.
- Add approval gates only where risk or governance requires them.
- Keep pipeline and deployment behavior repeatable and observable.
