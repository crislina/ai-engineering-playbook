# Observability

Load when adding runtime diagnostics or operational controls.

- Preserve correlation or trace context across service and asynchronous boundaries.
- Logs explain events; metrics quantify behavior; traces locate latency; alerts request action.
- Instrument critical workflows, dependency calls, latency, failure rate, and background work.
- Use structured fields and stable error/event codes where they aid investigation.
- Never log secrets, tokens, credentials, or sensitive payloads.
- Alert on user impact with actionable thresholds and runbooks; review noise.
