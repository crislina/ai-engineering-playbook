# Terraform

Load only for Terraform infrastructure changes.

- Pin providers and protect remote state with encryption, access control, and locking.
- Review plans before apply and keep environment inputs outside reusable modules.
- Create modules around cohesive ownership and reuse, not every resource.
- Avoid hidden manual dependencies; document imports and state migrations.
- Treat resource replacement, secret exposure, and provider upgrade as explicit review risks.
- Validate and plan the smallest affected scope before deployment.
