# Out of Scope

## Purpose

Clarify what this repository is not intended to cover.

## Current Exclusions

- Production application source code.
- Secrets, credentials, or private operational data.
- Tool-specific lock-in unless a guide explicitly targets that tool.
- Exhaustive framework documentation that is better maintained upstream.
- Authentication implementation.
- Notification systems.
- Audit logging implementation.
- RBAC implementation.
- AI recommendation engines.
- Production deployment automation.
- Full application templates unless explicitly added as a project goal.

## Rule

If a request touches an out-of-scope item, stop and ask whether the scope should change before implementation.

## Review

Update this file when project scope changes or when recurring requests need a clear boundary.
