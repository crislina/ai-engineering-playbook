# Project Overview

## Project

`ai-engineering-playbook`

## Background

A collection of reusable AI collaboration guides, software engineering principles, language-specific best practices, and project templates.

## Goals

- Provide a reusable operating model for AI-assisted engineering work.
- Capture engineering standards that can be copied into new projects.
- Keep guidance modular by global, backend, frontend, and project-specific concerns.
- Prevent AI assistants from repeatedly re-litigating settled project decisions.
- Make approval, workflow, architecture, and implementation expectations explicit.

## Features

- Global AI collaboration rules.
- Backend engineering standards.
- Frontend UI and React standards.
- Project vocabulary and decision records.
- POC, roadmap, and out-of-scope tracking.

## Tech Stack

- Markdown documentation.
- Git repository structure.
- Designed for Claude, Codex, and other AI coding assistants.

## Primary Users

- Engineers collaborating with AI coding assistants.
- Technical leads defining team engineering conventions.
- Project maintainers creating reusable development playbooks.
