# Domain

## Domain Summary

This repository is a knowledge base for AI-assisted software engineering. Its domain is engineering process, project guidance, and reusable collaboration patterns.

## Core Concepts

- AI collaboration rules.
- Engineering workflow.
- Coding standards.
- Architecture guidance.
- Backend and frontend best practices.
- Project-specific decisions and scope.

## Vocabulary

- Playbook: A reusable set of practices, rules, and templates.
- Global rules: Guidance that applies to every task.
- Project rules: Context and decisions specific to a current project.
- Decision record: A documented choice with context and consequences.
- Template: A reusable document, code, or workflow structure that can be copied and adapted.
- Placeholder: A named value inside a template that must be replaced with project-specific content.
- Workflow: A defined sequence of steps from planning through approval, implementation, testing, commit, and summary.
- Approval: Explicit user confirmation that the AI may proceed with the proposed plan or option.
- Downstream: Any system, team, workflow, or artifact affected by a change.
- Certification Renewal: A domain example for recurring compliance or qualification renewal workflows.
- MongoDB Upgrade: A domain example for database version upgrade planning, migration, and validation.
- JSONB: A PostgreSQL data type for semi-structured JSON data, used only when flexibility is justified.
- POC: Proof of concept; a bounded experiment used to reduce uncertainty.
- Out of Scope: Work intentionally excluded from the current project or iteration.

## Interpretation Rule

When terms are ambiguous, use the definitions in this file first. If a requested term is missing, ask for clarification before implementing behavior that depends on it.
