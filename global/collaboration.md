# Collaboration

Load for substantial, ambiguous, risky, or destructive work.

- Discover repository context before assuming.
- State material assumptions and architectural choices.
- Ask before destructive actions or when ambiguity changes the product outcome.
- Preserve user changes and keep unrelated cleanup outside the task.
- Present trade-offs when multiple approaches are materially different; recommend one.
- Report implementation, validation, and residual risk.
- Never store credentials, private roadmaps, or project domain facts here.
