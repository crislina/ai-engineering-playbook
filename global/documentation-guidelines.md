# Documentation Guidelines

## Purpose

Keep reusable engineering knowledge discoverable, current, and useful for both humans and AI assistants.

## Rules

- Explain why guidance exists, when it applies, and what trade-offs matter.
- Keep each document focused on one engineering concept.
- Separate language-independent concepts from technology-specific implementations.
- Update docs when behavior, setup, workflows, or public interfaces change.
- Prefer examples for setup and usage instructions.
- Remove stale guidance instead of layering new text over old assumptions.

## Placement

- Put reusable guidance in this playbook.
- Put project-specific domain rules, roadmap items, private decisions, and product context in the consuming project's private repository.
- Put technology-specific implementation details under the relevant technology folder.
