# Workflow

Load for substantial implementation.

1. Identify requested outcome, affected scope, and applicable project rules.
2. Route to the minimum playbook context.
3. Plan the smallest coherent change.
4. Implement in the repository's existing style.
5. Validate the narrow behavior first; broaden for shared or critical paths.
6. Report changed behavior, validation performed, and unresolved risk.

A task is done only when the requested outcome works or a concrete limitation is stated. Do not mix unrelated refactors, formatting, or generated artifacts into the change.
