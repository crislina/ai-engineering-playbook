# Responsive Layout

Load when a UI must work across viewport sizes or variable content.

- Preserve the primary workflow at each viewport; use progressive disclosure for secondary detail.
- Give boards, tables, toolbars, and fixed-format controls stable responsive constraints.
- Prevent text overlap, clipping, and content-driven layout shifts.
- Decide intentionally whether dense data scrolls, reflows, hides columns, or changes representation.
- Verify common viewport sizes with realistic longest content, empty states, and validation messages.
